# 八叉树 / 体素下采样

| 目标 | 类型 | 说明 |
|------|------|------|
| `octree` | **INTERFACE** | 哈希体素 Medoid、FastOctree、中心近邻八叉树 |

## 链接关系

```text
octree
  ├── pcl_common
  ├── Eigen3
  └── TBB::tbb
```

消费：`target_link_libraries(foo PRIVATE octree)`。不在默认伞目标内；仅 `full` 导出。

## API 契约（摘要）

- 生产默认：`Ddx::octree::downsampleMedoidIndices`（原点对齐整数体素真 Medoid）
- 求解前抽稀：`downsampleFirstIndices`
- 叶 Medoid（包围盒对齐）：`downsampleOctreeMedoidIndices` / `FastOctree`
- 流式/显示代表点：`CenterNearestOctree`
- 与缓存法向同用时：索引下采样后 `pcl::copyPointCloud` 同步抽点与法向（勿重估法向）
