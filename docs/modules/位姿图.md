# 位姿图

| 目标 | 类型 | 说明 |
|------|------|------|
| `pose_graph_opt` | **SHARED** | Ceres 位姿图优化（`PoseGraphOptimizer` / `CeresPoseGraphSolver`） |
| `pose_graph_tool` | **SHARED** | 连通分组与 MST 全局系传播（`PoseGraphGrouper` / `PoseGlobalSystem`） |

路径：`pose_graph/pose_graph_opt/`、`pose_graph/pose_graph_tool/`。两目标互不链接。

## 链接关系

```text
pose_graph_opt
  ├── logging
  ├── registration_type
  └── Eigen / Ceres

pose_graph_tool
  ├── common ──► logging / Eigen
  ├── logging
  ├── registration_type
  ├── graph          （MST / 连通分量）
  └── Eigen
```

消费：

```cmake
target_link_libraries(foo PRIVATE pose_graph_opt)   # PGO
target_link_libraries(foo PRIVATE pose_graph_tool)  # 分组 / 全局系传播
```

均不在默认伞目标 `scan_register` 内；仅 `full` 导出。头文件安装前缀：`<pose_graph_opt/...>`、`<pose_graph_tool/...>`。

## API 契约（摘要）

### pose_graph_opt

- `PoseGraphOptimizer::addNode/addEdge` → `setFixedNode`（可选）→ `optimize`
- 边信息矩阵 Ω：`AlignResult::information_`（`loadFromAlignResults`）；默认 I
- 约定：`T_rel` 满足 `G_src ≈ G_tgt * T_rel`（即 `T_rel = G_tgt^{-1} * G_src`）
- `getEdgeReports()`：当前全局位姿相对测量边的 SE(3) 残差（非点云 RMS）

### pose_graph_tool

- `PoseBase::setLidarFrames/setAlignResults` → `initialization`
- `PoseGlobalSystem::process`：单连通分量时 MST+DFS 写出 `map<name, Matrix4d>`
- `PoseGraphGrouper::process`：多连通分量分组；`getGroupInfos` 抽子集
