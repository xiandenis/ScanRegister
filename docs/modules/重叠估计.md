# 重叠估计

| 目标 | 类型 | 说明 |
|------|------|------|
| `overlap_estimation` | **INTERFACE** | 体素重叠估计、配准重叠子集提取 |

## 链接关系

```text
overlap_estimation
  ├── pcl_common / pcl_search
  ├── Eigen3
  └── OpenMP（可选）
```

消费：`target_link_libraries(foo PRIVATE overlap_estimation)`。不在默认伞目标内；仅 `full` 导出。

## API 契约（摘要）

| 类 | 用途 |
|----|------|
| `OverlapEstimator` | 体素哈希 + 距离阈 → 重叠比与索引（可区域结果） |
| `RegistrationOverlapExtractor` | 初值 SE(3) + 半径邻域 + 法向一致性 → src/tgt 重叠子集 |

`RegistrationOverlapExtractor` 的 `guess` 须为刚体：点 `p' = R p + t`，法向 `n' = R n`。
