# 分辨率估计

| 目标 | 类型 | 说明 |
|------|------|------|
| `resolution_estimate` | **SHARED** | 径向深度直方图体素、分位数场景尺度体素、曲率有界调制 |

## 链接关系

```text
resolution_estimate
  ├── logging
  ├── registration_type   # VoxelSceneClass
  ├── pcl_common
  └── Eigen3
```

消费：`target_link_libraries(foo PRIVATE resolution_estimate)`。不在默认伞目标内；`full` 导出。

## API 契约（摘要）

| 类 | 用途 |
|----|------|
| `Histogram` | 径向深度分箱频次 |
| `ResolutionEstimate` | 众数箱 → 离散体素档位 |
| `PercentileResolutionEstimate` | P50/P75/P90 → 推荐体素；可选曲率调制与 `VoxelSceneClass` |

**坐标系**：深度 = `‖p‖`（站心为原点）。`FramedCloud` 读入后若文件本为站心系，估计前须 `p' + origin` 折回文件坐标。
