# 配准初始化

| 目标 | 类型 | 说明 |
|------|------|------|
| `registration_initializer` | **SHARED** | 测站帧 Root / 子体素 / 法向 / 分辨率初始化 |

## 链接关系

```text
registration_initializer
  ├── registration_type / point_cloud_io / file_system / common / logging
  ├── octree / resolution_estimate / depth_map_tool
  ├── small_gicp
  ├── pcl_* / opencv_world / Eigen3 / TBB
```

消费：`target_link_libraries(foo PRIVATE registration_initializer)`。`full` 导出；不在默认伞目标内。

## API 契约（摘要）

| API | 用途 |
|-----|------|
| `initalState` | 写 LidarFrame 元数据（Root/子体素槽） |
| `initializd` | 读盘→Root 筛选→Medoid 子体素+法向→体素分辨率 |
| `check` | 校验 HAS_CALCU 与落盘 PCD |
| `estimateNormalsKnn` | SmallGicpTbb（默认）或 PclOmp |
| `AngleDownsample` | 站心全景角栅格赢家索引 |

**坐标系**：`FramedCloud` load 后折回 `local+origin`，再做径向深度与角栅格。
