# 配准类型

| 目标 | 类型 | 说明 |
|------|------|------|
| `registration_type` | **SHARED** | 测站/边/状态数据结构与 JSON IO |

## 链接关系

```text
registration_type
  ├── common
  ├── logging
  ├── Eigen3
  ├── pcl_common / pcl_search
  └── RapidJSON（头文件）
```

消费：`target_link_libraries(foo PRIVATE registration_type)`，或经伞目标 `scan_register::scan_register`（party 面已纳入）。

## API 契约（摘要）

| 类型 / 类 | 用途 |
|-----------|------|
| `ScanInfo` / `LidarFrame` | 测站元数据、体素缓存路径、全局矩阵 |
| `AlignResult` | 配准边；`rms_` 为已开方 RMSE [m] |
| `StationGraph` / `StationStatus` | 图顶点边与网页进度 |
| `VoxelSceneClass` | 体素曲率调制场景提示（权威定义） |
| `LidarFrameIO` / `AlignResultIO` / `StationStatusIO` | JSON 读写 |

头文件包含示例：`#include <registration_type/registration_type.hpp>`。
