# 公共基础模块

CMake 包：`scan_register`。`common` / `file_system` / `logging` 为 **SHARED**；`graph` 为 **INTERFACE**（纯头文件）。

| 目标 | 头文件入口 | 职责 |
|------|------------|------|
| `common` | `<common/common.hpp>` 等 | 位姿/坐标工具、E57 几何、WorkingFrame、内存调度 |
| `file_system` | `<file_system/file_system.hpp>` 等 | 可移植路径与通配、字符串/分词 |
| `logging` | `<logging/logging.hpp>` 等 | 进程内统一 LogManager（spdlog） |
| `graph` | `<graph/graph.hpp>` | 通用图算法：MST / 连通分量 / Dijkstra（纯 std，无 Boost） |

> **命名区分**：`graph` ≠ `robust_rough/robin` 的【ROBIN 图核心】（配准外点兼容图），也 ≠ `teaser::Graph`。

## 链接关系

```text
scan_register (INTERFACE)
  ├── common ──► logging ──► scan_register_spdlog / Threads
  ├── file_system
  ├── logging
  └── graph（INTERFACE，无额外链接依赖）
```

消费：链接 `scan_register` 伞目标即可带上 `graph`；或 `target_link_libraries(foo PRIVATE graph)`。

## 安装范围
