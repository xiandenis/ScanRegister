# 粗全局配准

| 目标 | 类型 | 说明 |
|------|------|------|
| `robust_global_reg` | **STATIC** | 站间粗全局配准（`Ddx::RobustGlobalReg`）；**纯内存入口** |

公共点云读写见独立模块说明：[`点云IO.md`](点云IO.md)（`point_cloud_io` / `FramedCloud`）。

## 链接关系

```text
robust_global_reg
  ├── robust_matcher ──► (robust_rough/*)
  ├── common / logging / file_system
  └── Eigen / RapidJSON
```

消费：`target_link_libraries(foo PRIVATE robust_global_reg)`。若需读盘另链 `point_cloud_io`（见点云 IO）。不在默认伞目标 `scan_register` 内。

## 输入契约（摘要）

- 调用方负责加载与局部化；推荐 `point_cloud_io::load` → `FramedCloud`，rebase 后用 `.cloud` 再 `run(src, tgt)`。
- `use_compass == true` 时输入必须是站心坐标系（站心在 `(0,0,0)`）。
