# 粗全局配准

| 目标 | 类型 | 说明 |
|------|------|------|
| `robust_global_reg` | **STATIC** | 站间粗全局配准（`Ddx::RobustGlobalReg`）；**纯内存入口** |
| `point_cloud_io` | **SHARED** | 点云多格式 I/O（同领域；由调用方/测试链接，非库硬依赖） |

## 链接关系

```text
robust_global_reg
  ├── robust_matcher ──► (robust_rough/*)
  ├── common / logging / file_system
  └── Eigen / RapidJSON

point_cloud_io（消费者侧）
  └── logging / PCL（las_fast；PDAL 已移除）
```

消费：`target_link_libraries(foo PRIVATE robust_global_reg)`；若需读盘另链 `point_cloud_io`。不在默认伞目标 `scan_register` 内。

## 输入契约（摘要）

- 读盘用 `point_cloud_io::load` → `FramedCloud`（局部云 + `origin`）；算法仍可吃 `.cloud`。作业级共用 `WorkingFrame` 由上层处理。
- `use_compass == true` 时输入必须是站心坐标系（站心在 `(0,0,0)`）。
- 规格：[`../superpowers/specs/2026-11-10-framed-cloud-io-design.md`](../superpowers/specs/2026-11-10-framed-cloud-io-design.md)
