# 粗全局配准

| 目标 | 类型 | 说明 |
|------|------|------|
| `robust_global_reg` | **STATIC** | 站间粗全局配准内核（`Ddx::RobustGlobalReg`）；**纯内存入口** |
| `rough_global_reg` | **STATIC** | 业务门面（`Ddx::RoughGlobalReg`）：`ScanInfo` → FramedCloud → 内核 → 世界系 `AlignResult` |

公共点云读写见独立模块说明：[`点云IO.md`](点云IO.md)（`point_cloud_io` / `FramedCloud`）。

## 链接关系

```text
rough_global_reg
  ├── robust_global_reg
  │     ├── robust_matcher ──► (robust_rough/*)
  │     ├── common / logging / file_system
  │     └── Eigen / RapidJSON
  ├── point_cloud_io
  ├── registration_type
  └── logging / file_system / Eigen / PCL
```

消费：

- 内核：`target_link_libraries(foo PRIVATE robust_global_reg)`；若需读盘另链 `point_cloud_io`。
- 门面：`target_link_libraries(foo PRIVATE rough_global_reg)`（传递内核与 IO）。

二者均不在默认伞目标 `scan_register` 内；`full` install 清单含两者。

## 输入契约（摘要）

### 内核 `RobustGlobalReg`

- 调用方负责加载与局部化；推荐 `point_cloud_io::load` → `FramedCloud`，rebase 后用 `.cloud` 再 `run(src, tgt)`。
- `use_compass == true` 时输入必须是站心坐标系（站心在 `(0,0,0)`）。

### 门面 `RoughGlobalReg`

- **`ScanInfo`**：`lasFn_` → FramedCloud；无罗盘 rebase 到源 origin；有罗盘折站心。
- **`LidarFrame`**：`voxel_3` 站心系缓存直读（勿再 FramedCloud 局部化）；须 `has_station_origin_`；折回用站心。
- 罗盘：**必须站心系**；无站心不能开。
- `guess` / `AlignResult.matrix_` 均为**文件/世界系**。
- 无路径字符串 API（已删除）。
