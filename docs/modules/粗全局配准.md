# 粗全局配准

| 目标 | 类型 | 说明 |
|------|------|------|
| `robust_global_reg` | **STATIC** | 站间粗全局配准（`Ddx::RobustGlobalReg`） |
| `point_cloud_io` | **SHARED** | 点云多格式 I/O（本模块硬依赖，已一并迁入） |

## 链接关系

```text
robust_global_reg
  ├── robust_matcher ──► (robust_rough/*)
  ├── point_cloud_io ──► logging / PCL / PDAL
  ├── common / logging / file_system
  └── Eigen / RapidJSON
```

消费：`target_link_libraries(foo PRIVATE robust_global_reg)`。不在默认伞目标 `scan_register` 内。
