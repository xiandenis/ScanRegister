# 粗全局配准

| 目标 | 类型 | 说明 |
|------|------|------|
| `robust_global_reg` | **STATIC** | 站间粗全局配准（`Ddx::RobustGlobalReg`）；**纯内存入口** |
| `point_cloud_io` | **SHARED** | 点云多格式 I/O（同领域；由调用方/测试链接，非库硬依赖） |

## 链接关系

```text
robust_global_reg
  ├── robust_matcher ──► (robust_rough/*)
  ├── common / logging / file_system
  └── Eigen / RapidJSON

point_cloud_io（消费者侧）
  └── logging / PCL / PDAL
```

消费：`target_link_libraries(foo PRIVATE robust_global_reg)`；若需读盘另链 `point_cloud_io`。不在默认伞目标 `scan_register` 内。

## 输入契约（摘要）

- 调用方负责加载与 WorkingFrame / 站心局部化后再 `run(src, tgt)`。
- `use_compass == true` 时输入必须是站心坐标系（站心在 `(0,0,0)`）。
