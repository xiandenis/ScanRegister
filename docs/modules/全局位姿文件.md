# 全局位姿文件

| 目标 | 类型 | 说明 |
|------|------|------|
| `global_matrix_file` | **SHARED** | 多站全局位姿 JSON 读写（`GlobalMatrixFileIO`） |

## 链接关系

```text
global_matrix_file
  ├── common ──► logging / Eigen
  ├── logging
  └── RapidJSON（头文件）
```

消费：`target_link_libraries(foo PRIVATE global_matrix_file)`。不在默认伞目标 `scan_register` 内；仅 `full` 导出。

## API 契约（摘要）

- `GlobalMatrixFileIO::loading(path, map)` / `saving(path, map)`
- JSON：`Transformation` 数组，元素含 `name`、`rotation`、`translation` 字符串；保存时写 `version: 1`
- 单阵南向串辅助在实现内私有（`BaseMatrixFileIO::readMatrix/writeMatrix`），公共面只暴露批量表
