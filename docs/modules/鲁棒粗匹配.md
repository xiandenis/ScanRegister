# 鲁棒粗匹配（robust_rough）

目录：[`robust_rough/`](../../robust_rough/)。CMake：`add_subdirectory(robust_rough)`。

| 目标 | 类型 | 说明 |
|------|------|------|
| `robust_matcher` | **STATIC** | 对外主入口：FPFH + ROBIN + GNC |
| `robin` | **STATIC** | 图论内点结构 |
| `teaser` | **STATIC** | TEASER++ 配准核心与 Align/Respondence 封装 |
| `pmc` | **STATIC** | 最大团 |
| `matcher_points` / `matcher_kdtree` / `matcher_hnswlib` / `matcher_tsl` | INTERFACE | 点云与近邻头模块（按 STATIC 叶子约定管理） |
| `xenium` | INTERFACE | robin 的 vendored 无锁头依赖 |

## 链接关系

```text
robust_matcher
  ├── robin ──► pmc
  │         └── xenium
  ├── matcher_points ──► Eigen / TBB
  ├── matcher_kdtree ──► matcher_points
  ├── matcher_hnswlib
  └── matcher_tsl

teaser ──► pmc / Eigen / FLANN / PCL
```

Include 根：`robust_rough/`（`<matcher_points/...>`、`<robin/...>`、`<teaser/...>`、`<xenium/...>`）；HNSW 为 `<hnswlib/...>`。

消费：`target_link_libraries(foo PRIVATE robust_matcher)` / `teaser`，或 `scan_register::…`。二者均不在默认伞目标 `scan_register` 内。
