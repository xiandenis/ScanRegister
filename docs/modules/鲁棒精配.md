# 鲁棒精配（robust_refine + trim_icp）

目录：[`robust_refine/`](../../robust_refine/)；另 [`trim_icp/`](../../trim_icp/) 在仓库根（不并入 `robust_refine/`）。  
CMake：`add_subdirectory(robust_refine)` 后 `add_subdirectory(trim_icp)`。

| 目标 | 类型 | 说明 |
|------|------|------|
| `basic_icp` | **STATIC** | Basic / Robust / FRICP 等基础 ICP |
| `small_gicp` | **STATIC** | 轻量并行 GICP（vendored） |
| `genz_icp` | **STATIC** | GenZ-ICP（依赖 `matcher_tsl`） |
| `fast_gicp` | INTERFACE | Fast-GICP / NDT 头文件（无 .cpp） |
| `trim_icp` | **SHARED** | TrimICP：重叠裁剪 + 可选 NC + BasicICP（仓库根） |

## 链接关系

```text
basic_icp ──► Eigen / OpenMP
small_gicp ──► Eigen / OpenMP
fast_gicp ──► PCL / Eigen / OpenMP
genz_icp ──► matcher_tsl / Eigen / TBB / PCL (+ Sophus vendored)
trim_icp (SHARED) ──► basic_icp / octree / PCL / Eigen / OpenMP
```

Include 根：`robust_refine/`（`<basic_icp/...>` 等）；`trim_icp` 用仓库根（`<trim_icp/...>`）。

消费：显式 `target_link_libraries(foo PRIVATE small_gicp)` / `trim_icp` 等；不在默认伞目标 `scan_register` 内。  
`genz_icp_pair` 默认关（`-DBUILD_GENZ_ICP_PAIR=ON`；已可链 `point_cloud_io`）。  
顶层默认编 `trim_icp_*_test` / `*_bench`（`SCAN_REGISTER_IS_TOP_LEVEL`）。
