# 深度图工具

| 目标 | 类型 | 说明 |
|------|------|------|
| `depth_map_tool` | **SHARED** | 全景深度图生成与格式转换（`DepthMapTool`） |

## 链接关系

```text
depth_map_tool
  ├── common（PanoramaUtil）
  ├── opencv_world
  ├── pcl_common
  ├── TBB::tbb
  └── Eigen3
```

消费：`target_link_libraries(foo PRIVATE depth_map_tool)`。不在默认伞目标内；仅 `full` 导出。  
与 `fastreg_filter` 无 CMake 硬依赖；典型流水线可先 `depth_create*` 再差分滤波。

## API 契约（摘要）

- 投影：`depth_create` / `depth_create_tbb`（可选 `Matrix4d` 变换）→ `CV_32FC1`，像素取最近深度
- 格式：float↔4uchar、32F→16U、水平环带扩展/还原、深度分段 uchar
