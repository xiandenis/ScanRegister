## 1. 空间点 ↔ 全景像素（E57 标准）

### 1.0 坐标系与图像约定

| 项 | 约定 |
|----|------|
| 笛卡尔系 | 右手系；**\(Z\) 向上**（E57：UP）；原点为测站 / 投影中心 |
| 全景图 | 宽 \(W\)、高 \(H\)（正整数）；像素 \((0,0)\) 在 **左上角**；\(u\) 向右增、\(v\) 向下增 |
| 投影模型 | E57 `sphericalRepresentation`（球面影像） |
| 满球标定 | \(\texttt{pixelWidth}=2\pi/W\)，\(\texttt{pixelHeight}=\pi/H\)（弧度/像素） |

下文角度默认 **弧度**；需要时再写度数。

---

### 1.1 正向：空间点 → 全景像素

输入：测站系点 \(\mathbf{p}=(x,y,z)\)，各分量有限。

#### 步骤 1 — 斜距

\[
r = \sqrt{x^{2}+y^{2}+z^{2}}
\]

| 量 | 取值范围 | 说明 |
|----|----------|------|
| \(x,y,z\) | \(\mathbb{R}\)（有限） | 输入 |
| \(r\) | \([0,+\infty)\) | \(r=0\) 或非有限 → **不投像素** |

#### 步骤 2 — 单位方向

\[
\hat{x}=\dfrac{x}{r},\quad
\hat{y}=\dfrac{y}{r},\quad
\hat{z}=\dfrac{z}{r}
\]

| 量 | 取值范围 |
|----|----------|
| \(\hat{x},\hat{y},\hat{z}\) | \([-1,1]\)，且 \(\hat{x}^{2}+\hat{y}^{2}+\hat{z}^{2}=1\) |

#### 步骤 3 — E57 球坐标 RAE 中的方位与仰角

\[
\theta = \operatorname{atan2}(y,\,x) = \operatorname{atan2}(\hat{y},\,\hat{x})
\qquad\text{（`sphericalAzimuth`）}
\]

\[
\varphi = \arcsin(\hat{z}) = \arcsin\!\left(\dfrac{z}{r}\right)
\qquad\text{（`sphericalElevation`，相对水平面，向上为正）}
\]

| 量 | E57 名 | 取值范围 | 几何含义 |
|----|--------|----------|----------|
| \(\theta\) | `sphericalAzimuth` | \((-\pi,\,\pi]\) | \(+\hat{X}\to 0\)；绕 \(+\hat{Z}\) **逆时针** |
| \(\varphi\) | `sphericalElevation` | \([-\pi/2,\,\pi/2]\) | 天顶 \(+\pi/2\)；水平 \(0\)；天底 \(-\pi/2\) |
| \(r\) | `sphericalRange` | \((0,+\infty)\) | 斜距（米）；本步投像素只需方向 |

（度数：\(\theta^\circ\in(-180^\circ,180^\circ]\)，\(\varphi^\circ\in[-90^\circ,90^\circ]\)。）

笛卡尔 ↔ RAE（对照）：

\[
\begin{aligned}
x &= r\cos\varphi\,\cos\theta \\
y &= r\cos\varphi\,\sin\theta \\
z &= r\sin\varphi
\end{aligned}
\]

#### 步骤 4 — 连续像素坐标

满球：

\[
\texttt{pixelWidth} = \dfrac{2\pi}{W},\qquad
\texttt{pixelHeight} = \dfrac{\pi}{H}
\]

| 量 | 取值范围 |
|----|----------|
| \(\texttt{pixelWidth}\) | \((0,\,2\pi]\) |
| \(\texttt{pixelHeight}\) | \((0,\,\pi]\) |

E57 球面投影：

\[
X = \dfrac{W}{2} - \dfrac{\theta}{\texttt{pixelWidth}}
= W\left(\dfrac{1}{2} - \dfrac{\theta}{2\pi}\right)
\]

\[
Y = \dfrac{H}{2} - \dfrac{\varphi}{\texttt{pixelHeight}}
= H\left(\dfrac{1}{2} - \dfrac{\varphi}{\pi}\right)
\]

| 量 | 理论取值范围（角取满域） | 对应 |
|----|--------------------------|------|
| \(X\) | \([0,\,W]\) | \(\theta=\pi\Rightarrow X=0\)；\(\theta=0\Rightarrow X=W/2\)；\(\theta\to-\pi\Rightarrow X\to W\) |
| \(Y\) | \([0,\,H]\) | \(\varphi=+\pi/2\Rightarrow Y=0\)（天顶）；\(\varphi=0\Rightarrow Y=H/2\)；\(\varphi=-\pi/2\Rightarrow Y=H\)（天底） |

#### 步骤 5 — 整数像素下标

\[
u = \operatorname{clamp}\!\big(\lfloor X\rfloor,\; 0,\; W-1\big),\qquad
v = \operatorname{clamp}\!\big(\lfloor Y\rfloor,\; 0,\; H-1\big)
\]

| 量 | 取值范围 |
|----|----------|
| \(u\) | \(\{0,1,\ldots,W-1\}\)（列） |
| \(v\) | \(\{0,1,\ldots,H-1\}\)（行） |

双线性采样用连续 \((X,Y)\)：\(X\) 可对 \(W\) 取模水平环绕；\(Y\) 夹在 \([0,\,H)\)。

#### 正向一览

```text
(x,y,z) → r>0 → θ=atan2(y,x)∈(-π,π] → φ=asin(z/r)∈[-π/2,π/2]
        → X=W(1/2-θ/(2π)) → Y=H(1/2-φ/π)
        → (u,v)∈{0..W-1}×{0..H-1}
```

---

### 1.2 反向：全景像素 → 空间方向（单位向量）

像素只决定 **视线方向**；深度／斜距 \(r>0\) 需另给（深度图、测距等）。无 \(r\) 时输出单位向量 \(\hat{\mathbf{p}}\)，等价 \(r=1\)。

#### 步骤 1 — 像素 → 连续坐标（像素中心）

对整数像素 \((u,v)\)：

\[
X = u + \dfrac{1}{2},\qquad
Y = v + \dfrac{1}{2}
\]

| 量 | 取值范围 |
|----|----------|
| \(u\) | \(\{0,\ldots,W-1\}\) |
| \(v\) | \(\{0,\ldots,H-1\}\) |
| \(X\) | \((0,\,W)\) |
| \(Y\) | \((0,\,H)\) |

（若输入已是连续采样坐标，则直接令 \(X,Y\) 为该连续值，跳过 \(+1/2\)。）

#### 步骤 2 — 连续像素 → E57 方位 / 仰角

满球下由 §1.1 步骤 4 反解：

\[
\theta = \left(\dfrac{W}{2} - X\right)\cdot\texttt{pixelWidth}
= \pi\left(1 - \dfrac{2X}{W}\right)
= 2\pi\left(\dfrac{1}{2} - \dfrac{X}{W}\right)
\]

\[
\varphi = \left(\dfrac{H}{2} - Y\right)\cdot\texttt{pixelHeight}
= \dfrac{\pi}{2}\left(1 - \dfrac{2Y}{H}\right)
= \pi\left(\dfrac{1}{2} - \dfrac{Y}{H}\right)
\]

| 量 | 取值范围（\(X\in(0,W),\,Y\in(0,H)\) 时） |
|----|------------------------------------------|
| \(\theta\) | 约 \((-\pi,\,\pi)\)（边界随 \(X\) 贴边） |
| \(\varphi\) | 约 \((-\pi/2,\,\pi/2)\) |

建议将 \(\theta\) 再归到 \((-\pi,\,\pi]\)（与 E57 一致）。

#### 步骤 3 — RAE → 单位方向 / 空间点

\[
\begin{aligned}
\hat{x} &= \cos\varphi\,\cos\theta \\
\hat{y} &= \cos\varphi\,\sin\theta \\
\hat{z} &= \sin\varphi
\end{aligned}
\]

| 量 | 取值范围 |
|----|----------|
| \(\hat{x},\hat{y},\hat{z}\) | \([-1,1]\)，单位向量 |

若已知斜距 \(r>0\)：

\[
\mathbf{p} = r\,\hat{\mathbf{p}} = (r\hat{x},\,r\hat{y},\,r\hat{z})
\]

| 量 | 取值范围 |
|----|----------|
| \(r\) | \((0,+\infty)\) |
| \(\mathbf{p}\) | 测站系 \(\mathbb{R}^{3}\setminus\{\mathbf{0}\}\) |

#### 反向一览

```text
(u,v) → X=u+1/2, Y=v+1/2
      → θ=2π(1/2-X/W) ∈ (-π,π]
      → φ=π(1/2-Y/H) ∈ [-π/2,π/2]
      → p̂=(cosφ cosθ, cosφ sinθ, sinφ)
      → p = r·p̂   （若给定 r>0）
```

### 1.3 与 `PanoramaUtil` 的等价写法（实现）

内部常用 **天顶距** \(\varphi_z=\arccos(\hat{z})=\pi/2-\varphi\in[0,\pi]\)：

| 方向 | 公式 |
|------|------|
| 空间 → 纹理 | \(u_{\mathrm{tex}}=1/2-\theta/(2\pi)\)，\(v_{\mathrm{tex}}=\varphi_z/\pi\) |
| 纹理 → 像素 | \(u=\lfloor u_{\mathrm{tex}}W\rfloor\)，\(v=\lfloor v_{\mathrm{tex}}H\rfloor\)（再夹紧） |
| 像素 → 空间 | \(u_{\mathrm{tex}}=(u+1/2)/W\)，\(v_{\mathrm{tex}}=(v+1/2)/H\)；\(\theta=2\pi(1/2-u_{\mathrm{tex}})\)，\(\varphi_z=\pi\,v_{\mathrm{tex}}\)；\(\hat{\mathbf{p}}=(\sin\varphi_z\cos\theta,\,\sin\varphi_z\sin\theta,\,\cos\varphi_z)\) |

满球下与 §1.1 / §1.2 **同一映射**。API：`math_pixel_from_xyz` / `math_xyz_from_pixel`。

### 1.4 典型方向对照（满球）

| 空间方向 | \(\theta\) | \(\varphi\) | 约在图像位置 |
|----------|------------|-------------|--------------|
| \(+\hat{X}\) | \(0\) | \(0\) | 中心 \((W/2,\,H/2)\) |
| \(+\hat{Y}\) | \(+\pi/2\) | \(0\) | 水平中线偏左 |
| \(-\hat{X}\) | \(\pi\) | \(0\) | 左缘附近 |
| \(-\hat{Y}\) | \(-\pi/2\) | \(0\) | 水平中线偏右 |
| \(+\hat{Z}\)（天顶） | （任意） | \(+\pi/2\) | 顶边 \(Y\to 0\) |
| \(-\hat{Z}\)（天底） | （任意） | \(-\pi/2\) | 底边 \(Y\to H\) |

## 2. 设备原理（双轴码盘）

架站三维激光扫描仪由 **单点测距激光 + 双轴码盘** 组成：快轴带动光束在竖直方向扫一周，慢轴带动整机在水平方向步进，从而铺满测站周围可视球面。

本节只讲 **机械与读数角域**；读数如何映到 §1 的 E57 \((\theta,\varphi)\) 见后续「码盘 → E57」节。

### 2.1 双轴读数角域

| 轴 | 角色 | 码盘读数 / 正常站扫角域 | 增大方向 |
|----|------|-------------------------|----------|
| **横轴码盘**（快轴） | 控制光束相对水平面的「垂直」读数 | 硬件 **\([0^\circ,\,360^\circ)\)**（增量码盘可为 \(360^\circ\) 整数倍，使用前归一到一周）；**连续整周循环** | 同向连续转（不在 \(180^\circ\) 折返） |
| **竖轴码盘**（慢轴） | 控制测站水平方位 | 硬件可读满周 **\([0^\circ,\,360^\circ)\)**；**正常站扫有效推进 \([0^\circ,\,180^\circ]\)**（§2.3） | **顺时针**（俯视，见 §2.4） |

符号（与后文一致）：

| 符号 | 含义 |
|------|------|
| \(\theta_1\) | **竖轴码盘**读数（设备水平角） |
| \(\varphi_1\) | **横轴码盘**读数（设备垂直向读数） |

**竖轴零点（现行约定）：** \(\theta_1=0^\circ\) **先定义为测站系 \(+\hat{X}\) 方向**（与 §1 E57 方位 \(\theta=0\) 同零点）。若日后标定发现设备零位有固定偏置，再单独加零偏项，不改本节「名义零点 = \(+\hat{X}\)」的写法。

另有斜距 \(r\)（与 E57 `sphericalRange` 同一物理量）及强度等，不在本节展开。

### 2.2 横轴：连续转 \(360^\circ\)，不是往复 \(180^\circ\)

横轴按同一转向循环：\(0^\circ\to360^\circ\to0^\circ\to\cdots\)。

- **不会**转到 \(180^\circ\) 再机械回到 \(0^\circ\) 再加速。  
- 读数落在 \([0^\circ,180^\circ]\) 与 \((180^\circ,360^\circ)\) 两段，是 **同一转向下的连续一周**。  
- 后半周在球面／光学上解释为 **倒镜**（相对前半周 **正镜**）：是 **映射分段**，不是轴在 \(180^\circ\) 处折返。

因此：正倒镜覆盖所需的「垂直方向」变化，都由横轴 **转满一周** 完成。

### 2.3 竖轴 \([0,180]\) + 横轴整周 = 一轮正常站扫

竖轴相对慢转。**正常站扫**策略：

1. 竖轴 \(\theta_1\) 在 \([0^\circ,\,180^\circ]\) 内缓慢推进（顺时针增大）；  
2. 每个竖轴位置上，横轴 \(\varphi_1\) **连续转满** \([0^\circ,\,360^\circ)\)（前半周正镜 + 后半周倒镜）。

一轮扫描的码盘点落在：

\[
\theta_1 \in [0^\circ,\,180^\circ],\qquad
\varphi_1 \in [0^\circ,\,360^\circ)
\]

水平方向的「全周」不靠竖轴再转满 \(360^\circ\)，而靠 **横轴倒镜段** 与正镜段一起，在 E57 方位 \(\theta\) 上拼出一周（公式后文给出）。

### 2.4 竖轴顺时针 vs E57 方位逆时针

**视角：** 与 §1 相同——测站右手系，\(Z\) 向上；**俯视**水平面（从天顶往下看，视线沿 \(-\hat{Z}\)）。

| 量 | 零点 | 增大方向 |
|----|------|----------|
| 竖轴码盘 \(\theta_1\) | \(0^\circ = +\hat{X}\) | **顺时针**：\(+\hat{X}\to-\hat{Y}\to-\hat{X}\to+\hat{Y}\) |
| E57 方位 \(\theta\)（§1，`atan2(y,x)`） | \(0 = +\hat{X}\) | **逆时针**：\(+\hat{X}\to+\hat{Y}\to-\hat{X}\to-\hat{Y}\) |

**同零点、反向：** 正镜、仅看水平时，方向对应关系为 \(\theta \leftrightarrow -\theta_1\)（再归到 E57 的 \((-\pi,\pi]\)）。  
**不要**默认 \(\theta=\theta_1\)（那只在「竖轴也逆时针增大」时成立）。

| \(\theta_1\)（顺时针码盘） | 空间水平方向 | E57 \(\theta\)（示意） |
|---------------------------|--------------|------------------------|
| \(0^\circ\) | \(+\hat{X}\) | \(0\) |
| \(90^\circ\) | \(-\hat{Y}\) | \(-\pi/2\) |
| \(180^\circ\) | \(-\hat{X}\) | \(\pi\)（或 \(-\pi\)） |
| \(270^\circ\)（若硬件给出） | \(+\hat{Y}\) | \(+\pi/2\) |

### 2.5 与 §1 的关系（本阶段）

| 层 | 内容 |
|----|------|
| 设备 | 码盘 \((\theta_1,\varphi_1)\) + 斜距 \(r\)（§2） |
| 展现 | E57 \((r,\theta,\varphi)\) → 全景像素（§1） |

数据流概念上：

```text
码盘 (θ₁, φ₁, r) ──(正倒镜 + 顺时针反号)──► E57 (r, θ, φ) ──§1──► 像素 (u,v)
```

**本节不写** 正倒镜显式公式；码盘角字段定义见 **§3**，码盘 → E57 见后续节。

## 3. 码盘角定义（设备数据 · API 边界）

本节定义 **作为数据存什么**：RealOne / 设备点云在接口上携带的角度，是码盘读数，**不是** §1 的 E57 \((\theta,\varphi)\)。

### 3.1 字段与角域

角度单位：**度**（与设备读数一致）；实现里若用弧度，须在边界显式换算。

| 字段 | 符号 | 物理含义 | 正常站扫角域 | 硬件可读角域 | 增大方向 / 零点 |
|------|------|----------|--------------|--------------|-----------------|
| 竖轴码盘 | \(\theta_1\) | 设备 **水平角**（方位向） | \([0^\circ,\,180^\circ]\) | \([0^\circ,\,360^\circ)\)（归一化后） | **顺时针**（俯视）；\(\theta_1=0^\circ\Rightarrow+\hat{X}\)（§2.4） |
| 横轴码盘 | \(\varphi_1\) | 设备 **垂直向读数**（光束俯仰相关） | \([0^\circ,\,360^\circ)\) | 同左（连续整周） | 同向连续转；分段见 §3.3 |
| 斜距 | \(r\) | 测距 | \(r>0\)（米） | — | 与 E57 `sphericalRange` 同义 |

归一化：

\[
\mathrm{wrap}_{360}(x) = x \bmod 360 \in [0^\circ,\,360^\circ)
\]

使用前将原始码盘计数归到一周；正常站扫语义下再要求 \(\theta_1\in[0^\circ,180^\circ]\)。

### 3.2 一点上的码盘表示

一个有效测点在设备侧至少包含：

\[
\big(\theta_1,\,\varphi_1,\,r\big)
\quad\text{（可选：强度、时间戳等）}
\]

| 约定 | 说明 |
|------|------|
| **API 进出** | 存、传、输出均用码盘角 \((\theta_1,\varphi_1)\)，外加 \(r\) 等 |
| **不在边界改成 E57** | 赋色 / 投全景时，在模块 **内部** 再换成 §1 的 \((\theta,\varphi)\) |
| **与空间点** | 若已有 \((x,y,z)\)，可按 §1 得 E57；写回设备角时走「E57 → 码盘」（后文），不要把 E57 \(\theta\) 直接当 \(\theta_1\) |

### 3.3 横轴分段：正镜 / 倒镜（读数标签）

\(\varphi_1\) 连续一周中的数值分段（§2.2），仅作几何标签：

| \(\varphi_1\) | 标签 | 说明 |
|---------------|------|------|
| \([0^\circ,\,180^\circ]\) | **正镜** | 横轴前半周；边界 \(\varphi_1=180^\circ\) 归入正镜 |
| \((180^\circ,\,360^\circ)\) | **倒镜** | 横轴后半周，仍同向续转 |

正式「码盘 → E57」见 **§4**。

### 3.4 与 §1 E57 角的对照（勿混用符号）

| | 码盘（§3） | E57（§1） |
|--|------------|-----------|
| 水平 | \(\theta_1\) 顺时针，度，正常站扫 \([0,180]\) | \(\theta=\operatorname{atan2}(y,x)\) 逆时针，弧度 \((-\pi,\pi]\) |
| 垂直 | \(\varphi_1\) 设备读数 \([0,360)\) | \(\varphi=\arcsin(z/r)\) 仰角 \([-\pi/2,\pi/2]\) |
| 零点 | \(\theta_1=0\Rightarrow+\hat{X}\) | \(\theta=0\Rightarrow+\hat{X}\)（同）；垂直零点语义不同 |

### 3.5 RealOneCloud（概念）

```text
输入/输出点： (θ₁, φ₁, r, intensity, …)     ← 码盘角
内部赋色：    (θ₁, φ₁) → E57 (θ, φ) → 像素   ← 仅内部
```

（类型字段名实现时建议直书 `horizontal_encoder_deg` / `vertical_encoder_deg` 一类，避免再叫含糊的 azimuth/zenith。）

---

**§3 已确认：** 正常站扫 \((\theta_1,\varphi_1)\in[0,180]\times[0,360)\)；\(\theta_1=0=+\hat{X}\)；API 只存码盘；正倒镜仅 \(\varphi_1\) 分段标签。

## 4. 码盘 → E57

目标：由设备码盘 \((\theta_1,\varphi_1)\) 与斜距 \(r\) 得到 §1 的 E57 RAE \((r,\theta,\varphi)\)，再可按 §1 投像素。

**前提：** \(\theta_1,\varphi_1\) 已 \(\mathrm{wrap}_{360}\)；单位先用 **度** 算中间量，最后 \(\theta,\varphi\) 用 **弧度**（与 E57 / `atan2` 一致）。

辅助：

\[
\mathrm{wrap}_{\pm 180}(x^\circ)
=\mathrm{wrap}_{360}(x^\circ+180^\circ)-180^\circ
\in (-180^\circ,\,180^\circ]
\]

（把任意度归到与 E57 方位同形的有符号一周。）

天顶距（度，仅中间量）：\(\varphi_z^\circ\)；E57 仰角（度）：\(\varphi^\circ=90^\circ-\varphi_z^\circ\)。

### 4.1 正镜：\(\varphi_1 \in [0^\circ,\,180^\circ]\)

\[
\varphi_z^\circ = \varphi_1,\qquad
\varphi^\circ = 90^\circ - \varphi_1,\qquad
\theta^\circ = \mathrm{wrap}_{\pm 180}(-\theta_1)
\]

| 量 | 取值范围（正常站扫 \(\theta_1\in[0,180]\)） |
|----|----------------------------------------------|
| \(\varphi_z^\circ\) | \([0^\circ,\,180^\circ]\) |
| \(\varphi^\circ\) | \([-90^\circ,\,90^\circ]\)（\(\varphi_1=0\Rightarrow\) 天顶；\(\varphi_1=90\Rightarrow\) 水平；\(\varphi_1=180\Rightarrow\) 天底） |
| \(\theta^\circ\) | \([-180^\circ,\,0^\circ]\)（\(\theta_1=0\Rightarrow 0\)；\(\theta_1=180\Rightarrow\pm 180\)） |

### 4.2 倒镜：\(\varphi_1 \in (180^\circ,\,360^\circ)\)

\[
\varphi_z^\circ = 360^\circ - \varphi_1,\qquad
\varphi^\circ = 90^\circ - \varphi_z^\circ,\qquad
\theta^\circ = \mathrm{wrap}_{\pm 180}(180^\circ - \theta_1)
\]

| 量 | 取值范围（正常站扫 \(\theta_1\in[0,180]\)） |
|----|----------------------------------------------|
| \(\varphi_z^\circ\) | \((0^\circ,\,180^\circ)\) |
| \(\varphi^\circ\) | \((-90^\circ,\,90^\circ)\) |
| \(\theta^\circ\) | \((0^\circ,\,180^\circ]\)（与正镜合起来铺满水平一周） |

（\(\varphi_1=180^\circ\) 已归入 §4.1。）

### 4.3 小结表

| \(\varphi_1\) | 段 | \(\varphi_z^\circ\) | E57 仰角 \(\varphi^\circ\) | E57 方位 \(\theta^\circ\) |
|---------------|----|---------------------|---------------------------|---------------------------|
| \([0,180]\) | 正镜 | \(\varphi_1\) | \(90-\varphi_1\) | \(\mathrm{wrap}_{\pm180}(-\theta_1)\) |
| \((180,360)\) | 倒镜 | \(360-\varphi_1\) | \(90-\varphi_z\) | \(\mathrm{wrap}_{\pm180}(180-\theta_1)\) |

### 4.4 化为 E57 弧度并投像素

\[
\theta = \theta^\circ\cdot\frac{\pi}{180},\qquad
\varphi = \varphi^\circ\cdot\frac{\pi}{180},\qquad
r \text{ 不变}
\]

| 量 | E57 角域 |
|----|----------|
| \(\theta\) | \((-\pi,\,\pi]\) |
| \(\varphi\) | \([-\pi/2,\,\pi/2]\) |
| \(r\) | \((0,+\infty)\)（无效则勿赋色） |

其后：

```text
(θ₁, φ₁, r) ──§4──► (r, θ, φ)_E57 ──§1──► 像素 (u,v)
```

或先由 RAE 还原方向 \(\hat{\mathbf{p}}\)（§1 笛卡尔公式）再 `PanoramaUtil::math_pixel_from_xyz`（满球等价）。

### 4.5 数值对照（正常站扫，示意）

| \(\theta_1\) | \(\varphi_1\) | 段 | \(\theta^\circ\) | \(\varphi^\circ\) | 含义 |
|--------------|---------------|----|------------------|-------------------|------|
| \(0\) | \(0\) | 正镜 | \(0\) | \(+90\) | \(+\hat{X}\) 水平零位上的天顶向 |
| \(0\) | \(90\) | 正镜 | \(0\) | \(0\) | \(+\hat{X}\) 水平 |
| \(0\) | \(270\) | 倒镜 | \(180\) | \(0\) | \(-\hat{X}\) 水平（倒镜） |
| \(90\) | \(90\) | 正镜 | \(-90\) | \(0\) | \(-\hat{Y}\) 水平 |

（\(\varphi_1=0\) 时 \(\varphi^\circ=+90\) 为天顶，方位 \(\theta\) 在天顶退化，实现可任意保留。）

---

**§4 已确认：** 正镜 \(\varphi_z=\varphi_1,\;\theta^\circ=\mathrm{wrap}_{\pm180}(-\theta_1)\)；倒镜 \(\varphi_z=360-\varphi_1,\;\theta^\circ=\mathrm{wrap}_{\pm180}(180-\theta_1)\)。

## 5. E57 → 码盘

目标：由 E57 \((r,\theta,\varphi)\)（或等价由空间点经 §1 得到）写回 **正常站扫码盘** \((\theta_1,\varphi_1)\)（§3）。

**前提：** \(\theta\in(-\pi,\pi]\)，\(\varphi\in[-\pi/2,\pi/2]\)；下面中间量用度：

\[
\theta^\circ = \theta\cdot\frac{180}{\pi}\in(-180^\circ,180^\circ],\qquad
\varphi^\circ = \varphi\cdot\frac{180}{\pi}\in[-90^\circ,90^\circ]
\]

天顶距：\(\varphi_z^\circ = 90^\circ - \varphi^\circ\in[0^\circ,180^\circ]\)。\(r\) 原样带回。

### 5.1 双解说明

同一视线在几何上可对应正镜 / 倒镜两组码盘（横轴一周内可扫到两次）。  
**正常站扫**约束 \(\theta_1\in[0^\circ,180^\circ]\)、\(\varphi_1\in[0^\circ,360^\circ)\) 时，用 **§5.2** 按 \(\theta^\circ\) 分段得到 **唯一** 解（与 §4 互逆）。

### 5.2 一次球面覆盖 → 正常站扫码盘（推荐）

\[
\begin{cases}
\theta_1 = -\theta^\circ,\quad
\varphi_1 = \varphi_z^\circ = 90^\circ - \varphi^\circ,
& \theta^\circ \in (-180^\circ,\,0^\circ]
\quad\text{（正镜；含 }\theta^\circ=0\text{）} \\[10pt]
\theta_1 = 180^\circ - \theta^\circ,\quad
\varphi_1 = 270^\circ + \varphi^\circ,
& \theta^\circ \in (0^\circ,\,180^\circ)
\quad\text{（倒镜）}
\end{cases}
\]

边界 \(\theta^\circ = \pm 180^\circ\)：归入正镜，\(\theta_1=180^\circ\)，\(\varphi_1=90^\circ-\varphi^\circ\)。

| \(\theta^\circ\) | 段 | \(\theta_1\) | \(\varphi_1\) |
|------------------|----|--------------|---------------|
| \(0\) | 正镜 | \(0\) | \(90-\varphi^\circ\) |
| \((-180,\,0)\) | 正镜 | \(-\theta^\circ\in(0,180)\) | \(90-\varphi^\circ\in[0,180]\) |
| \((0,\,180)\) | 倒镜 | \(180-\theta^\circ\in(0,180)\) | \(270+\varphi^\circ\in(180,360)\) |
| \(\pm 180\) | 正镜（约定） | \(180\) | \(90-\varphi^\circ\) |

结果应满足：

\[
\theta_1 \in [0^\circ,\,180^\circ],\qquad
\varphi_1 \in [0^\circ,\,360^\circ)
\]

再经 §4 应回到同一 \((\theta,\varphi)\)（天顶附近方位可差 \(360^\circ\) 整数倍或任意，属退化）。

### 5.3 几何单段逆（不强制正常站扫竖轴半周时）

由 \(\varphi_z^\circ=90^\circ-\varphi^\circ\)：

| 解 | 公式 | \(\varphi_1\) 落在 |
|----|------|---------------------|
| 正镜解 | \(\varphi_1=\varphi_z^\circ\)，\(\theta_1=\mathrm{wrap}_{360}(-\theta^\circ)\) | \([0,180]\) |
| 倒镜解 | \(\varphi_1=360^\circ-\varphi_z^\circ\)，\(\theta_1=\mathrm{wrap}_{360}(180^\circ-\theta^\circ)\) | \([180,360]\) |

写回 RealOne / 正常站扫点云时 **优先 §5.2**，不要只套正镜解（会丢掉倒镜半周，或把 \(\theta_1\) 推出 \([0,180]\)）。

### 5.4 选用约定

| 场景 | 做法 |
|------|------|
| 设备点本来就有码盘 | **保留**原始 \((\theta_1,\varphi_1)\)，勿先转 E57 再 §5 逆回 |
| 全景网格 / 空间点 → 正常站扫码盘 | **§5.2** |
| 只需某一几何段 | §5.3 |

```text
像素 / 空间点 ──§1──► E57 (r,θ,φ) ──§5.2──► 码盘 (θ₁, φ₁, r)
码盘 ──§4──► E57 ──§1──► 像素     （赋色主路径）
```

---

**§5 已确认：** 按 \(\theta^\circ\le 0\) 正镜、\(>0\) 倒镜写回 \(\theta_1\in[0,180]\)。

## 6. 测站点云 → 设备正常扫描

目标：把**测站坐标系**下的点云 \(\{(x,y,z,\ldots)\}\) 写成设备 **正常站扫** 码盘点 \(\{(\theta_1,\varphi_1,r,\ldots)\}\)，角域与 §2.3 / §3 一致。

### 6.1 前提

| 项 | 约定 |
|----|------|
| 输入坐标系 | 测站右手系，\(Z\) 向上；原点 = 测站 / 投影中心（与 §1 相同） |
| 输入点 | \(\mathbf{p}=(x,y,z)\)，可选强度等；**不必**已有码盘角 |
| 输出 | 正常站扫码盘 \((\theta_1,\varphi_1,r)\)，\(\theta_1\in[0^\circ,180^\circ]\)，\(\varphi_1\in[0^\circ,360^\circ)\) |
| 语义 | 「若该视线由本机正常站扫采到，码盘应记成什么」——**不是**改测站系坐标本身 |

若输入点**本来就有设备码盘**，保留原始 \((\theta_1,\varphi_1)\)（§5.4），不要对本节再逆一遍。

### 6.2 流水线（逐点）

```text
测站系 (x,y,z)
    │
    ▼  §1.1 步骤 1–3
E57 (r, θ, φ)          ← 弧度；θ∈(-π,π]，φ∈[-π/2,π/2]
    │
    ▼  §5.2（度制分段）
正常站扫码盘 (θ₁, φ₁, r)
```

**一步公式链（实现时可直算，不必显式存中间量）：**

1. \(r=\sqrt{x^{2}+y^{2}+z^{2}}\)；\(r\le 0\) 或非有限 → **跳过该点**。  
2. \(\theta=\operatorname{atan2}(y,x)\)，\(\varphi=\arcsin(z/r)\)。  
3. \(\theta^\circ=\theta\cdot 180/\pi\)，\(\varphi^\circ=\varphi\cdot 180/\pi\)。  
4. 按 §5.2：

\[
\begin{cases}
\theta_1=-\theta^\circ,\quad
\varphi_1=90^\circ-\varphi^\circ,
& \theta^\circ\in(-180^\circ,0^\circ] \\[6pt]
\theta_1=180^\circ-\theta^\circ,\quad
\varphi_1=270^\circ+\varphi^\circ,
& \theta^\circ\in(0^\circ,180^\circ)
\end{cases}
\]

\(\theta^\circ=\pm 180^\circ\)：\(\theta_1=180^\circ\)，\(\varphi_1=90^\circ-\varphi^\circ\)。

5. 可选：由 \((\theta_1,\varphi_1,r)\) 经 §4 再还原笛卡尔，应回到原方向（天顶/天底方位退化除外）。

### 6.3 输出点云形态

| 字段 | 来源 |
|------|------|
| \(\theta_1,\varphi_1\) | §6.2 |
| \(r\) | 斜距 |
| 强度 / 其他属性 | 从输入原样拷贝（本变换不改正） |
| \((x,y,z)\) | 可保留作旁路，或由码盘+§4 重建；**API 边界以码盘为准**（§3） |

整云语义：每个有效点落在正常站扫矩形角域 \([0,180]\times[0,360)\) 内，正镜 / 倒镜由 \(\varphi_1\) 分段自然出现（§3.3）。

### 6.4 与赋色路径对照

| 方向 | 路径 |
|------|------|
| **测站点云 → 正常扫描（本节）** | \((x,y,z)\) → §1 → E57 → §5.2 → 码盘 |
| **设备正常扫描 → 赋色** | 码盘 → §4 → E57 → §1 → 像素 |

二者在角变换上互逆；中间统一走 E57，避免把 \(\operatorname{atan2}\) 直接当 \(\theta_1\)。

### 6.5 退化与注意

| 情况 | 处理 |
|------|------|
| \(r=0\) / NaN / Inf | 不输出该点 |
| 天顶 / 天底（\(\lvert\varphi\rvert\to\pi/2\)） | \(\theta\) 无意义；§5.2 仍给出一组 \((\theta_1,\varphi_1)\)，但方位不唯一 |
| 输入已在世界系 / 他站系 | **先**变换到本测站系，再走本节 |
| 需要「仅正镜解」等非正常站扫 | 用 §5.3，不要用本节 |

---

**§6 已确认：** 测站系 XYZ → §1 + §5.2 → 正常站扫码盘。
