# 公共基础_Dictionary

覆盖模块：`common`、`file_system`、`logging`。CMake 目标同名，默认 **SHARED**。

|--------|----------|--------------------------------------|------------------------|------------|
| common | logging | 【日志管理器】(LogManager) | 仓库内 | 调度/工具写日志 |
