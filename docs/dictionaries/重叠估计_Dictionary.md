# 重叠估计_Dictionary

覆盖模块：`overlap_estimation`（体素重叠估计、配准重叠子集提取）。  
**产物约定**：`overlap_estimation` 为 **INTERFACE**（纯头文件）。

与 `fastreg_filter`（深度图差分重叠率）、`robust_global_reg` 内重叠检查路径区分：本模块对点云做体素/半径邻域重叠度量与子集抽取。
